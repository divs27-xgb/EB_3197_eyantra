# Task 2B — Echo Balancer bike

Task 2B extends Task 2A by balancing the bike while turning it to yaw setpoints.

## Controller scripts

- [`lqr.py`](lqr.py): LQR controller using the Task 2A model and gains.
- [`pid.py`](pid.py): PID controller used for the final evaluated run.

Official portal submission bundles, scene files, and encrypted output files are intentionally excluded from this public repository. Local evaluation archives are preserved separately and are not part of this update.
