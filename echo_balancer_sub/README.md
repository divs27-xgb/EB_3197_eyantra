# e-Yantra Echo Balancer

Code, simulation work, and submitted artifacts for e-Yantra's Echo Balancer tasks.

## Task folders

- `Task0/`, `Task1A/`, `Task1B/`, and `Task1C/` contain earlier task code and outputs.
- `Task2A/` contains the bike balancing work: the Lagrangian model, helper scripts, and submission artifacts.

See [Task 2A README](Task2A/README.md) for the current model and file layout. Official simulator/evaluator downloads and local experiment logs are kept out of Git by `.gitignore`.
